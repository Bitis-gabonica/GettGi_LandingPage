## Project Overview

**GETT GI** is a landing page for a Senegalese livestock tracking and security solution. The product combines smart GPS collars, a mobile/web app, alert systems, and digital animal identification to help herders, cooperatives, and public institutions monitor and protect livestock.

The project brief is in `contenu.md` (French). Key content for the landing page:
- Three core value props: **Localiser** (track), **Sécuriser** (secure), **Identifier** (identify)
- Target audiences: herders, cooperatives, government/institutions
- Market stats: ~577,000 households involved in livestock, 22,000-30,000 cattle stolen/year (~2 billion FCFA losses)
- Business model: hardware kits + monthly subscription + enterprise deployments
- Contact: Abdoulaye Ly, +221 77 777 85 76, theabdoulay@gmail.com

## Status

This is a **greenfield project** — no framework or code has been set up yet. The only existing file is the project brief (`contenu.md`).

## Design Direction

Per the brief, the landing page tone should be: **direct, sober, convincing, minimal text**. The product is positioned as a local Senegalese solution, not abstract technology — it sells control, security, and management capability.

## Language

The landing page content is in **French**. Code comments and variable names should be in English.
